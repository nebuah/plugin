# Legal Document Review & Analysis

## Steps
1. Define the review scope — what types of provisions, risks, or issues to flag
2. Create a review checklist based on the engagement objectives
3. Organize documents by category (contracts, filings, correspondence, corporate records)
4. Review each document systematically against the checklist
5. Flag key provisions: unusual terms, risk areas, missing protections, ambiguities
6. Cross-reference related documents for consistency (e.g., amendment vs. original agreement)
7. Compile findings into a structured review memo organized by issue priority
8. Provide a risk-rated summary table for client decision-making

## Negative Constraints
- Never review documents without a defined scope — unfocused review wastes time and misses critical issues
- Never assume a document is the final version — always verify execution status and amendments
- Never skip cross-referencing between related documents — inconsistencies are common and material
- Never present findings without severity ratings — clients need prioritized actionable information

## Notes
- For large document sets, use keyword searching to prioritize high-risk documents before manual review
- Track review progress to ensure complete coverage
- Use standardized issue categories for consistency across engagements
